# Measured results

`runs/run1` to `runs/run10` hold the output of `run-all-v2.sh`, one run per folder, 12 files each (Dart appears twice: `dart.json` runs it as it builds, `dart_aot.json` runs the precompiled program). Every run used all eight cores of one rented server, inside the image built from the `Dockerfile` in this repository. The `kotlin.json` files in `run1` to `run10` come from before the Kotlin timing fix in commit `6240b7f`, and `runs/kotlin_after_fix` holds ten runs after it.

`jmh-java.json` and `jmh-kotlin.json` are the JMH output for Java and Kotlin with default tiered compilation, and `jmh-java-tiered-off.json` and `jmh-kotlin-tiered-off.json` are the same runs with `-XX:-TieredCompilation`. The website uses the tiered-off pair, because it gives the smaller ratio (Java 5.4 against 7.9, Kotlin 7.0 against 8.6), and `benchmarkdotnet.txt` is the BenchmarkDotNet table for C#. `../harness/medians_v2.json` holds the numbers the website uses: medians of the ten runs for most languages, JMH with tiered compilation off for Java and Kotlin, and BenchmarkDotNet with tiered compilation off for C#.

`googlebenchmark-cpp.json`, `go-testing-bench.txt` and `mitata-typescript.json` are the checks for C++, Go and TypeScript, run by `harness/checks/run-checks.sh` over the same scenario code. The website uses these three instead of the hand-written loops, because each gives the smaller ratio (C++ 15.1 against 17.7, Go 15.4 against 23.2, TypeScript 4.4 against 5.8). `dart-benchmark-harness.txt` and `swift-package-benchmark.txt` are the Dart and Swift checks (Dart: the benchmark_harness package, ten measurements; Swift: the Benchmark package with 1,000 passes per sample, because at one pass per sample the tool added about 120 ns of its own timing cost to every figure). The website uses both: Dart 6.6 against 7.2 from the loop, Swift 4.57 against 4.64. `python-pyperf.json`, `ruby-benchmark-ips.txt`, `php-phpbench.txt` and `dart-aot-benchmark-harness.txt` are the last four checks (pyperf, benchmark-ips, PHPBench, and benchmark_harness on the precompiled Dart program). The website uses pyperf for Python (5.57 against 5.90 from the loop) and the Dart tool for the precompiled row (3.92 against 4.70). Ruby and PHP keep the loop figures, because the tools agree within 3 percent (4.36 against 4.33, 3.94 against 3.83) and the loop is the smaller ratio. Every language has now been checked with a tool.
